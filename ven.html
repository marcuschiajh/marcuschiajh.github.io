Mini Coin-operated Vending Machine

Made using Arduino UNO


Features

- Accepts $1 coin only, other smaller coins will fall through the sorter.
- Buttons with LED to indicate options.
- Mechanism to return coin
- LED to indicate snack is dispensed

How it works

- When coin is inserted, the passive infrared sensor, detects the coin.
- The options light up.
- If coin return is selected, a servo diverts to coin in to the return slot.
- If the snack option is selected, a servo pushes the snack in to the dispensing slot.
